# ObservTools
**Professional observer and broadcast toolkit for Counter-Strike 2.**
ObservTools is a desktop application designed for CS2 observers and broadcast operators. It provides tools for camera control, HUDs, live match data and broadcast workflow automation.

## Features
* Observer tools for Counter-Strike 2
* Custom HUDs and broadcast overlays
* Camera and flythrough path management
* HLAE integration
* Game State Integration (GSI)
* OBS integration
* Match and tournament tools
* Automated CS2 and observer workflow

## Status

**Private Testing**
ObservTools is currently under active development and testing with selected users.
The software is not publicly available yet. Information about the public release will be announced separately.

## Requirements
* Windows 10 or later
* Counter-Strike 2
* HLAE
* OBS Studio
