# ObservTools

**Professional observer and broadcast production toolkit for Counter-Strike 2.**

ObservTools is a desktop application designed for CS2 observers and broadcast production. It brings HUD management, live match data, player webcams, flythroughs and observer workflow tools into one application.

**Current version: 1.0.6**

[Website](https://obs.qcn.kz) · [Latest Release](https://github.com/mad1cs/ObservTools/releases/latest)

## Features

### HUD System

* 7 built-in HUD themes
* Support for custom HUDs
* HUD, Player Glow and Grenade Trails color customization
* Separate CT/T palettes
* OBS Browser Source integration

### Flythroughs

* Automatic flythroughs during freeze time
* HLAE / `mirv_campath` integration
* `.campath` and `.dz` support
* Map-based licensing
* RU/EN flythrough names and descriptions
* Sequential and random playback modes

### Player Data

* Manual player and team management
* Excel import with a ready-to-use template
* Automatic player updates by SteamID64
* Matchroom import from FACEIT
* Matchroom import from FASTCUP
* Live player/team import from CS2 through GSI

### Webcams

* Up to 10 player webcam slots
* VDO.Ninja integration
* Automatic camera switching based on the currently observed player

### Matches

* Match creation and editing
* Bo1 / Bo3 / Bo5 support
* Score and match status management
* Manual team positioning
* Map veto management
* Automatic HUD synchronization

### KillFeed

* Real-time event processing engine
* Event deduplication
* Socket.IO and REST support

## Requirements

* Windows
* Counter-Strike 2
* OBS Studio
* HLAE

## Getting Started

1. Download the latest version from [Releases](https://github.com/mad1cs/ObservTools/releases/latest).
2. Create an account at [obs.qcn.kz](https://obs.qcn.kz).
3. Log in to ObservTools.
4. Configure your HUD, match data and observer tools.
